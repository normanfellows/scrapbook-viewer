# Scrapbook Viewer

A reusable viewing instrument for the *Catalogue as Thesis*.

The Scrapbook Viewer provides a consistent environment for exploring IIIF-based scrapbooks that support the arguments developed throughout the Catalogue. It establishes the architectural framework within which individual scrapbooks can be presented, while remaining independent of any particular scrapbook or proposition.

Version 0.1 is concerned with establishing the viewer architecture. Later versions will introduce enhanced navigation, annotations, contextual information, and deeper integration with the Catalogue.

## Design Principles

- One viewer, many scrapbooks.
- Stable architecture, changing content.
- Evidence first.
- Calm, uncluttered interface.
- Technology-independent design.
- Progressive enhancement.
